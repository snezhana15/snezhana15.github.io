# Snezhana Ismailaj — Portfolio

Personal portfolio site: **https://snezhana15.github.io**

Cybersecurity and digital forensics student at Drexel University (B.S. Computing & Security Technology, expected June 2027). The site covers my projects, experience, and education.

## Built with

- [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com)
- Deployed automatically to GitHub Pages with GitHub Actions on every push to `master`

## Run locally

```bash
npm install
npm run dev
```

All site content lives in `src/config.ts`.
